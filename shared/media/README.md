# Media

Prepared incident clips currently live in [../../social/x/clips/](../../social/x/clips/). Keep published raw-file URLs stable: do not rename an existing published clip without checking its consumers. New clips use `YYYY-MM-DD-location-incident.mp4`, with date meaning documented in the editorial record.
