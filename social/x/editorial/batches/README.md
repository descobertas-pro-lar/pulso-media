# Daily approval batches

Save each morning batch as `YYYY-MM-DD.md`. Include numbered final captions, media previews and asset URLs, sources and dates, proposed slots, approval or requested edits, and verified Buffer IDs/status after scheduling. Do not infer approval from a draft.

Include a separate reply-suggestions section with 3–5 target post URLs, ready-to-use Portuguese replies and a brief reason for each. These are user-posted suggestions, not automatically sent replies.
