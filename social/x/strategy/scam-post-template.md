## Required format

```text
🚨 CUIDADO COM O {scam_name}

{description}

{video or pic depicting id}
```

The last placeholder means a native video or picture depicting the scam, not literal placeholder text. Use an actual scam message, fake page, relevant screenshot, or footage showing the method. Do not substitute a decorative text card, banner or generic stock image. If using a reconstruction, clearly label it as illustrative; never present it as real evidence.

The description explains the lure, why it seems credible and how the deception works, in direct Brazilian Portuguese. Create alertness through concrete, verified details; avoid government-ad language, checklist-first advice, invented victims or unsupported urgency.

Keep source URLs and event/publication dates in the research/batch record. Retain visible source credits where present and attribute reported claims in the description when needed. This exact template does not require an extra standalone source line. Verify context and media before requesting publication approval. Redact exposed personal data and disable or obscure usable malicious links in screenshots without concealing the mechanics being explained.

This is a specific exception to the native-text-only rule: the caption is native X text, accompanied by meaningful evidence media, not text rendered into a picture. If suitable media is missing, record the gap and keep the post pending rather than call it ready. Verify the final text fits the account limit and preview the actual attachment for approval.
